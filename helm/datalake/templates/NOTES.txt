To access the services:

1. Port-forward to access UIs locally:
   kubectl port-forward -n {{ .Values.global.namespace }} svc/trino 8080:8080
   kubectl port-forward -n {{ .Values.global.namespace }} svc/airflow 8082:8080
   kubectl port-forward -n {{ .Values.global.namespace }} svc/spark-master 8083:8080
   kubectl port-forward -n {{ .Values.global.namespace }} svc/minio 9001:9001

2. Check pod status:
   kubectl get pods -n {{ .Values.global.namespace }}

3. View logs:
   kubectl logs -n {{ .Values.global.namespace }} -l app.kubernetes.io/name={{ include "datalake.name" . }}
